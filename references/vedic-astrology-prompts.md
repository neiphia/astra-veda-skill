# 印度占星（Vedic Astrology）星盘分析 Prompt 集

## 使用说明

本文档包含四大模块的 prompt，供 Gemini API 调用使用。

| 模块 | 调用次数 | 输入 | 上下文传递 |
|---|---|---|---|
| 模块零（排盘校验与回测） | 1 次 | 出生资料 + 本地引擎输出 + 历史 3-5 事件 | 供后续全部模块引用 |
| 大致分析 | 1 次 | 星盘 PDF + Prompt | 无 |
| 事业 | 4 次（自动依次） | 星盘 PDF + Phase 1 Prompt（首次）；前次输出 + 下一个 Phase Prompt（后续） | 每次输出作为下次输入的上下文 |
| 爱情 | 1 次 | 星盘 PDF + 用户性别 + Prompt | 无 |
| 人生指南 | 1 次 | 星盘 PDF + Prompt | 无 |

事业模块的 4 次调用为顺序执行：Phase 1 完成后自动发送 Phase 2（携带 Phase 1 的输出），以此类推。

模块零必须在模块一之前执行，其解读口径修正建议是后续 7 轮的硬性引用约束。

爱情模块的性别参数：前端用户在首页选择的性别（男/女）需填入爱情 Prompt 中的 **【性别：此处填入用户性别】** 占位符处，再发送给 Gemini。性别为必填项，未选择性别时前端不允许提交分析。

## 模块零：排盘校验与历史回测（Round 0 — Calibration）

- 输入：用户出生资料 + 本地 Swiss Ephemeris 引擎(scripts/vedic_engine.py)输出 + 用户提供的 3-5 个历史事件(年份+事件简述)

- 输出：排盘可信度评级 + 历史事件对照表 + 解读口径修正建议，供后续 7 轮引用

# Process
## Step 1：排盘数据校验
列出本地引擎算出的关键度数(上升、太阳、月亮、L10、AK、AmK、月亮宿)，与 PDF 读取值逐项比对。Sandhi 度数(0-1°/29-30°)不一致时必须标注"谨慎度"并以本地计算为准。

## Step 2：历史事件回测
对用户提供的每个历史事件，反推当时的大运(MD)/小运(AD)及行运(土星/木星/Rahu/Ketu 过本命宫)，判断星体能量实际以何种宫位主题显化。

## Step 3：解读口径校准
基于回测结果，识别本盘的"显化偏好"（例：Venus 若同时为 L5 与 L10，回测显示其能量更常走 L10 事业线而非 L5 恋爱线）。输出修正建议，明确告诉后续模块：哪些双主星倾向于走哪个宫位主题、哪些事件形式不应强行预测。

# Output Format
